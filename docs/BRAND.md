## 2. 标识（Logo）

图形语义：**蓝色六边形底座 + 白色盾牌 + 文档 + 青绿对勾**。

- 源图（设计稿，唯一真源）：`docs/brand/logo-source-企智审.png`
- 生成脚本：`scripts/brand/make-logo-assets.py`（**改版式改脚本再重跑，禁止手改 public 下的产物**）
- 组件：`components/brand/logo.tsx`（`LogoMark` / `LogoLockup`）
- 位图产物：`public/brand/mark-transparent-512.png`（页面内显示）、`mark-512.png`（白底兜底）
- 站点图标：`app/icon.svg`（**矢量孪生**，浏览器标签页专用，几何按位图重画）+ `public/favicon.ico`

### 抠图的唯一难点（改脚本前必读）

源图是白底位图，而**图标内部的白色盾牌与图外白底在图像上是连通的**
（通道在「对勾左下尖 ↔ 六边形右下边」之间，最窄处约 16px）。
因此任何「与画布边缘连通的近白 = 背景」的朴素抠图都会把盾牌一起抹掉。
现在的做法是「闭运算封住通道 → 从四边 floodfill 求外部 → 小块内部白放开」，
每一步的实测依据都写在脚本文件头。**改半径前先跑一遍 `_check.png` 对照图。**

另：外底实测是 `#F8F8F8`（不是纯白），而盾牌内部也是 `#F8F8F8` ——
**颜色无法区分内外**，只能靠几何。这也是斜坡阈值必须按 `#F8F8F8` 定、不能按纯白定的原因。

### 使用规则

1. **最小尺寸**：图形标不小于 20px；带字标不小于 28px 高。
2. **安全边距**：四周留白不小于图形高度的 1/4。
3. **深底直接用**：透明底产物已保留白色盾牌与青绿对勾，深色区块上无需再套白色底板。
   （这一点曾经不成立 —— 早期产物在深底上盾牌会消失，所以留了这条记录。）
4. **禁止**：拉伸变形、改色、加渐变/弥散光/投影、加外框。
5. 需要单色（印章、传真、单色印刷）时另行制作单色版，**不要**用滤镜把彩色版转灰。

| 用途 | 值 | 依据 | Token |
|---|---|---|---|
| 品牌蓝（锚点） | `#0068F8` | James 指定；LOGO 实测主蓝 `#0766EA` 同源 | `brand-500` |
| 深海军蓝（锚点，深色区块底） | `#0B2149` | James 指定；LOGO 实测深蓝 `#062151` 同源 | `brand-900` |
| 品牌浅（浅底图形、渐变高光） | `#4d8eff` | 六边形高光侧（icon.svg 渐变起点） | `brand-400` |
| 青绿对勾（锚点） | `#26D5A8` | James 指定；LOGO 实测对勾 `#10CDBB~#3BE3AD` 同源 | `accent-500` |
| 成功 | `#1f7a4d` | — | `success-600` |
| 警告 | `#a35a06` | — | `warning-600` |
| 危险 | `#b3261e` | — | `danger-600` |

其余色阶（brand-50~800 / accent-300~600）从锚点推算，**单一事实源是
`app/globals.css` 的 `@theme` 令牌**，本文档不复刻全表 ——
复刻一份就会在下次换色时变成第二个旧色板（`#0064e6`/`#002050`/`#10c8a8` 这版就是这么过时的）。

**换色必须回源图重新采样。** 旧色板 `#2f6097` 是上一版的钢蓝，
与新标志同屏会出现两种蓝 —— 2026-09-28 换标志时就是这样发现色板也必须一起换的。

青绿（`accent-*`）**只存在于品牌标志内部**（icon.svg 对勾、LOGO 位图、OG 图），
不做页面 UI 色 —— 页面 UI 用品牌蓝族。语义色只用于表达状态与严重级别，**不用于装饰**。

## 4. 中文排版（本项目的硬约束）

### 4.1 字重：只有两档真实效果（实测，不是推测）

实测方法：Windows Chrome + 微软雅黑，canvas 渲染「审核」两字（80px），
统计不透明像素数量（墨量）：

| 字重 | 墨量 | 结论 |
|---|---|---|
| 400 / 500 | 4925 | Regular |
| 600 / 700 / 800 / 900 | **7177（四者完全相同）** | Bold |

由此得出三条：

1. **`font-black`(900) 不会更粗**，也不会「合成描边糊成一团」（早期文档里这么写过，是错的）——
   它只是被静默映射成 Bold。想要更粗的视觉，加字重没用。
2. **`font-semibold`(600) 在 Windows 上就是 Bold**，在 macOS（PingFang 有真实 Semibold）上更细 ——
   同一处文字两端观感不一致。需要跨端一致时只用 400 / 700。
3. 体量感只能靠 **字号（clamp 视口缩放）+ 收紧行高 + 字距 + 品牌色高亮**。

规范：**新增代码只用 `font-normal`(400) 与 `font-bold`(700)**；
不写 500 / 600 / 800 / 900 —— 它们要么无效，要么跨端不一致。
存量代码里的 `font-semibold` 不批量替换（改动面大、Mac 端会突变），但含义知晓即可。

### 4.2 大标题不断行

中文词间无空格，固定 rem 字号在窄栏会把词劈开（「审／核」）。
⇒ 大标题一律 `text-[clamp(min,vw,max)]` + `sm:whitespace-nowrap`，配合手写 `<br>` 断点。
- 正文：`leading-7`（1.75）；中文没有大小写与斜体，层级只能靠字号/字重/间距/颜色
- 字体栈维持系统字体（PingFang / 微软雅黑 / 思源黑体），不自托管中文字体：
  思源黑体一个字重 8–10MB，为落地页引入得不偿失
- 禁用全角标点做装饰、禁「重磅/震撼」类词、禁用 emoji 代替图标

## 5. 语气

- 说**已实现**的，不说规划中的：未启用模型复核就写「模型复核尚未启用」
- 不写没测过的数字（准确率、处理时长、客户数）
- 示例一律标注「示例数据」，不出现真实企业名
- 判定权在人手里 —— 文案不得暗示"系统判定供应商合格"

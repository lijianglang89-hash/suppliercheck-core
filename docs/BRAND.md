# 品牌与标识规范

> 只写「照做」的部分。灵感来源、备选方案这类过程信息不进文档。

## 1. 品牌名层级（三层，主次不可颠倒）

| 层 | 名称 | 用在哪 |
|---|---|---|
| 主品牌 | **供应商智审** | 对外传播、口头称呼、站点 Logo 位、浏览器标签 |
| 法定全称 | 供应商资料智能审核系统 | 页脚、合同与备案、SEO title、`aria-label`、应用侧栏 |
| 拉丁名 | SupplierCheck | 域名、代码、英文材料、技术文档 |

规则：拉丁名**永远不做主视觉**，只做副标（`text-ink-400` / `text-[10px]`）。
中文为主、英文为辅，这不是审美偏好 —— 目标用户是中文采购与供应链团队。

统一写法：`SupplierCheck`（一个词，S 与 C 大写）。禁止 `Supplier Check` / `suppliercheck` / `SC`。

## 2. 标识（Logo）

图形语义：**一份文件 + 右下角判定徽章**。

不用盾牌的原因：盾牌讲的是"安全"，而本产品讲的是"逐条核对后给出可追溯的判定"；
且盾牌在 B2B 领域已被用滥到失去识别度。文件 + 勾同时命中「资料」与「结论」两件事。

- 组件：`components/brand/logo.tsx`（`LogoMark` / `LogoLockup`）
- 站点图标：`app/icon.svg`（深蓝圆角底 + 白描边图形，保证 16px 可辨）
- 描边风格与 `components/ui/icons.tsx` 同源（2px、圆角端点），与界面图标是一套语言

### 使用规则

1. **最小尺寸**：图形标不小于 20px；带字标不小于 28px 高。
2. **安全边距**：四周留白不小于图形高度的 1/4。
3. **颜色**：浅底用 `currentColor`（默认继承文字色，站点用 brand-700）；深底必须传 `inverse`
   （徽章底变白、勾变蓝）—— 否则会出现"白圆白勾"，勾直接消失。
4. **禁止**：拉伸变形、加渐变/弥散光/投影、替换描边颜色、给徽章勾换色、加外框。
5. 需要单色（如印章、传真、单色印刷）时用 `LogoMark` 继承 `currentColor` 即可，不要另做一版。

## 3. 配色

| 用途 | 值 | Token |
|---|---|---|
| 品牌主色 | `#2f6097` | `brand-600` |
| 品牌深（深色反转区块、Hover） | `#274e7b` / `#172c46` | `brand-700` / `brand-900` |
| 品牌浅（图形辅助、浅底） | `#457bb4` | `brand-500` |
| 成功 | `#1f7a4d` | `success-600` |
| 警告 | `#a35a06` | `warning-600` |
| 危险 | `#b3261e` | `danger-600` |

语义色只用于表达状态（通过 / 待确认 / 问题 / 严重级别），
**不用于装饰** —— 一旦颜色开始装饰，状态色就失去含义。

## 4. 中文排版（本项目的硬约束）

### 4.1 字重：只有两档真实效果（实测，不是推测）

实测方法：Windows Chrome + 微软雅黑，canvas 渲染「审核」两字（80px），
统计不透明像素数量（墨量）：

| 字重 | 墨量 | 结论 |
|---|---|---|
| 400 / 500 | 4925 | Regular |
| 600 / 700 / 800 / 900 | **7177（四者完全相同）** | Bold |

由此得出三条：

1. **`font-black`(900) 不会更粗**，也不会「合成描边糊成一团」（早期文档里这么写过，是错的）——
   它只是被静默映射成 Bold。想要更粗的视觉，加字重没用。
2. **`font-semibold`(600) 在 Windows 上就是 Bold**，在 macOS（PingFang 有真实 Semibold）上更细 ——
   同一处文字两端观感不一致。需要跨端一致时只用 400 / 700。
3. 体量感只能靠 **字号（clamp 视口缩放）+ 收紧行高 + 字距 + 品牌色高亮**。

规范：**新增代码只用 `font-normal`(400) 与 `font-bold`(700)**；
不写 500 / 600 / 800 / 900 —— 它们要么无效，要么跨端不一致。
存量代码里的 `font-semibold` 不批量替换（改动面大、Mac 端会突变），但含义知晓即可。

### 4.2 大标题不断行

中文词间无空格，固定 rem 字号在窄栏会把词劈开（「审／核」）。
⇒ 大标题一律 `text-[clamp(min,vw,max)]` + `sm:whitespace-nowrap`，配合手写 `<br>` 断点。
- 正文：`leading-7`（1.75）；中文没有大小写与斜体，层级只能靠字号/字重/间距/颜色
- 字体栈维持系统字体（PingFang / 微软雅黑 / 思源黑体），不自托管中文字体：
  思源黑体一个字重 8–10MB，为落地页引入得不偿失
- 禁用全角标点做装饰、禁「重磅/震撼」类词、禁用 emoji 代替图标

## 5. 语气

- 说**已实现**的，不说规划中的：未启用模型复核就写「模型复核尚未启用」
- 不写没测过的数字（准确率、处理时长、客户数）
- 示例一律标注「示例数据」，不出现真实企业名
- 判定权在人手里 —— 文案不得暗示"系统判定供应商合格"
